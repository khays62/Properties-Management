# OmniProperties

Production-oriented Property Management System built with:

- Django
- DRF
- PostgreSQL
- React
- TypeScript

## Deployment

Render deployment preparation and environment configuration are documented in
[docs/deployment/](./docs/deployment/README.md). The repository includes a
Render Blueprint in [`render.yaml`](./render.yaml); it does not deploy until
you create or sync the Blueprint in Render.
